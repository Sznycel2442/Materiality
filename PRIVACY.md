# Privacy

Materiality is a static, browser-based application. This repository does not
include an application server, analytics service, user accounts or a database.

## Data stored in the browser

Notes, favourites, interface preferences and any product photos added through
the interface are stored only in the browser's local storage on the device
where they were entered. They are not sent by this application to a server.
Clearing the browser's site data removes them.

## Third-party websites

The catalogue contains links to manufacturer pages, technical documentation and
some externally hosted product images. Opening those links, or loading an
external image, connects the browser directly to the relevant third party and
is subject to that party's privacy policy.

## Publishing contributions

Do not commit personal data, private product photos, access tokens, API keys,
passwords, certificates or local configuration. The repository's `.gitignore`
excludes common sensitive and machine-local files, but contributors remain
responsible for reviewing changes before publishing them.
